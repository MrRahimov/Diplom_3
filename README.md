# Diplom 3  

## UI-тесты для Stellar Burgers  

### Что сделано  
Написаны UI-автотесты с использованием Selenium и pytest  
Реализован паттерн POM  
Подключён Allure для отчётов  
Проверена работа в браузерах Chrome и Firefox  

### Проверки  
Переход в «Конструктор»  
Переход в «Ленту заказов»  
Открытие и закрытие модального окна ингредиента  
Увеличение счётчика ингредиента при добавлении  
Изменение счётчиков «За всё время» и «За сегодня»  
Появление номера заказа в разделе «В работе»  
Переход из аккаунта обратно в «Конструктор»  

### Как запустить тесты  
pip install -r requirements.txt
python -m pytest -m ui --alluredir=allure-results
allure serve allure-results
